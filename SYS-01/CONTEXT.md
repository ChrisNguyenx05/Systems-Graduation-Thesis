# 📖 CONTEXT: SYS-01 Business & Predictive Analytics Dashboard Domain Model

This document defines the **Ubiquitous Language** and operational boundaries for **SYS-01 (Business & Predictive Analytics Dashboard)** within the Financial Analytics & Fraud Detection Enterprise Platform.

---

## 📚 Ubiquitous Language & Terminology

### 1. Market Data & Visualization Concepts
- **OHLCV Candlestick**: Standard financial candlestick representation including Open, High, Low, Close, and Volume over a defined aggregation window (1m, 5m, 15m, 1h).
- **Tick Stream**: Discrete order execution event received in real-time from Binance WebSocket, containing timestamp, trade ID, price, quantity, and maker flag.
- **Technical Indicators**: Mathematical calculations based on historical price/volume, specifically SMA-20 (Simple Moving Average) and RSI-14 (Relative Strength Index).
- **Canvas Rendering**: Hardware-accelerated (WebGL / HTML5 Canvas) interactive chart rendering capable of displaying high-frequency updates without DOM bottleneck.

### 2. Predictive & AI Overlay Concepts
- **Price Forecast Path ($P_{t+15m}, P_{t+60m}$)**: The predicted future price trajectory generated by the deep learning model (LSTM) hosted in SYS-04, rendered as a distinctive dashed trendline with confidence bands.
- **Market Anomaly Pinpoint**: Visual indicator (Pin Red 🔴 marker) dynamically attached to a specific candlestick where the anomaly detection model (Isolation Forest) identified abnormal volume spikes, pump-and-dump dynamics, or order book spoofing.
- **Fraud Probability Score**: Continuous probability metric $[0.0, 1.0]$ computed by the LightGBM classifier for incoming financial transactions.
- **Risk Category Classification**: Categorical severity assigned to flagged transactions (`LOW`, `MEDIUM`, `HIGH - Pump & Dump`, `HIGH - Wash Trading`, `CRITICAL - Credit Card Theft`).

### 3. State Management & Resiliency Concepts
- **TTL Cache (Time-To-Live)**: In-memory caching mechanism (5 seconds threshold) used to throttle repeated queries to ClickHouse and prevent browser memory leaks.
- **Degraded Mode / Failover Banner**: Graceful degradation state triggered when SYS-04 (AI Serving) or SYS-05 (ClickHouse) is temporarily unreachable, falling back to cached or local snapshot data with user notification.
- **Circuit Breaker**: Software pattern that temporarily halts remote inference calls to SYS-04 when consecutive timeouts occur, protecting UI responsiveness.

## ⚙️ Operational Port Mapping & Isolation
- **Streamlit Web UI**: Port `8501` (External Host Binding: `http://localhost:8501`)
- **Internal Network**: Joined to Docker bridge network `fintech_net`
- **Dependencies**: Connects to `fastapi_serving:8000` (SYS-04), `clickhouse_server:8123` (SYS-05), `sys06_alert_dispatcher:8006` (SYS-06), and public Binance WebSocket stream (`wss://stream.binance.com:9443`).
