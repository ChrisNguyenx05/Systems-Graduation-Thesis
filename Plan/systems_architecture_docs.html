SYS-01: Business & Predictive Analytics Dashboard

Giao diện trực quan hóa dữ liệu nến tài chính Real-time, dự báo giá ngắn hạn và gắn cờ bất thường/gian lận.

Thông Số Kỹ Thuật A-Z

  • Mục tiêu: Trực quan hóa giá Crypto Real-time, lồng ghép AI Forecast (LSTM) & Marker Anomaly (Isolation Forest).
  • Ràng buộc SLA: WebSocket Tick Latency < 100ms, ClickHouse Polling 5s, REST AI Response < 200ms.
  • Input Data Schema: Binance WebSocket JSON, ClickHouse `crypto_klines_gold` Table, FastAPI Prediction JSON.
  • Output Data Schema: Plotly Candlestick Canvas + AI Dashed Line Overlay + Flagged Transactions Table.

SYS-02: Data Pipeline & Orchestration System

Điều phối tự động hóa các tiến trình ETL, huấn luyện lại AI và bảo trì Data Lakehouse với Apache Airflow.

Thông Số Kỹ Thuật A-Z

  • Mục tiêu: Quản lý tính phụ thuộc (Task Dependency), tự động retry lỗi, kiểm soát SLA execution timeouts.
  • Ràng buộc SLA: Historical Backfill < 30m, Spark Monitor < 1m, AI Model Retrain < 2h, Delta Housekeeping < 45m.
  • Input Data Schema: Binance CSV Zip URLs, ClickHouse Gold Feature Tables, Airflow Connections.
  • Output Data Schema: Parquet files on MinIO `crypto-bronze`, HTTP POST Retrain Trigger to SYS-04.

SYS-03: Infrastructure & Operations Center

Trung tâm giám sát vận hành hạ tầng Grafana + Prometheus theo dõi CPU, RAM, Disk I/O và Kafka Consumer Lag.

Thông Số Kỹ Thuật A-Z

  • Mục tiêu: Đảm bảo độ sẵn sàng 99.9% cho 11 Docker Containers, phát hiện trễ dữ liệu qua Kafka Consumer Lag.
  • Ràng buộc SLA: Metrics Scrape Interval = 15s, Alerting Notification SLA < 30s.
  • Input Data Schema: Prometheus OpenMetrics endpoints (`/metrics`) từ cAdvisor, Node & Kafka Exporters.
  • Output Data Schema: Grafana Dashboard Panels & Prometheus Alertmanager Payload triggers.

SYS-04: MLOps & Model Governance Center

Quản lý phiên bản mô hình MLflow Model Registry và phục vụ dự báo giá/gian lận qua REST API FastAPI.

Thông Số Kỹ Thuật A-Z

  • Mục tiêu: MLOps Experiment Tracking, Model Registry Versioning (Staging/Production), Zero-downtime Hot Reload.
  • Ràng buộc SLA: Prediction Latency SLA < 50ms (Batch=1), Input Requirement = Min 60 OHLCV candles.
  • Input Data Schema: REST JSON Body `{ "symbol": "BTCUSDT", "recent_ohlcv": [...] }`.
  • Output Data Schema: REST JSON Body `{ "predicted_price_15m": 64800, "trend": "BULLISH" }`.

SYS-05: Lakehouse & Database Management Portal

Quản lý kho dữ liệu Medallion 3 tầng (Bronze/Silver/Gold) trên MinIO S3 và ClickHouse OLAP Database.

Thông Số Kỹ Thuật A-Z

  • Mục tiêu: Lưu trữ dữ liệu Medallion Architecture, Delta Lake ACID Transactions, Time Travel, ClickHouse OLAP < 10ms.
  • Ràng buộc SLA: ClickHouse Single-key Query SLA < 10ms, Compression Ratio > 5:1.
  • Input Data Schema: Raw JSON stream from Binance, Parquet Files from Spark Stream.
  • Output Data Schema: ClickHouse OLAP Tables (`ReplacingMergeTree`, `SummingMergeTree`).

SYS-06: Operational Alerting & Notification System

Kênh gửi thông báo khẩn cấp tức thời về di động qua Telegram Bot API khi xảy ra thao túng thị trường hoặc sập hạ tầng.

Thông Số Kỹ Thuật A-Z

  • Mục tiêu: Đóng gói và phát đi tin nhắn cảnh báo 3 cấp độ (🔴 CRITICAL, ⚠️ WARNING, 🟢 INFO) dưới 3 giây.
  • Ràng buộc SLA: Delivery Latency SLA < 3s, Rate Limiter Max 10 msgs/min, Deduplication Window 300s.
  • Input Data Schema: JSON Event Payload `{ "alert_type": "MARKET_ANOMALY", "score": 0.96 }`.
  • Output Data Schema: Telegram Push Message với Markdown formatting & Emojis.
