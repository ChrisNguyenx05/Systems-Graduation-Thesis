1. Mục Tiêu & Mục Đích Hệ Thống

SYS-05 quản lý kho dữ liệu doanh nghiệp kết hợp giữa Data Lakehouse (Medallion Architecture 3 tầng trên MinIO S3) và cơ sở dữ liệu phân tích siêu tốc ClickHouse OLAP. Hệ thống duy trì tính năng Delta Lake Time Travel và phản hồi truy vấn SQL ad-hoc dưới 10ms.

🥉 Bronze Bucket

Lưu trữ dữ liệu thô (Raw JSON/CSV) từ Binance WebSocket & Bulk API.

s3://crypto-bronze/

🥈 Silver Bucket

Lưu trữ dữ liệu đã làm sạch dưới dạng Delta Lake Parquet (ACID + Time Travel).

s3://crypto-silver/

🥇 Gold Bucket

Tập dữ liệu Feature Store sẵn sàng cho mô hình AI huấn luyện.

s3://crypto-gold/

3. ClickHouse DDL SQL Schema

CREATE TABLE default.crypto_klines_gold ( symbol LowCardinality(String), open_time DateTime64(3, 'UTC'), open Float64, high Float64, low Float64, close Float64, volume Float64, updated_at DateTime DEFAULT now() ) ENGINE = ReplacingMergeTree(updated_at) PRIMARY KEY (symbol, open_time) ORDER BY (symbol, open_time);
