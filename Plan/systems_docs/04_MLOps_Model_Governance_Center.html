1. Mục Tiêu & Mục Đích Hệ Thống

SYS-04 quản lý toàn bộ vòng đời của các mô hình AI/ML (LSTM Price Forecast, Isolation Forest Anomaly, LightGBM Fraud Detection). Mô hình được theo dõi thí nghiệm trên MLflow UI (Port 5000) và nạp tự động vào FastAPI Serving Engine (Port 8000) để phản hồi yêu cầu dự báo dưới 50ms mà không gây gián đoạn hệ thống (Zero-downtime hot-reload).

4. FastAPI Production Server Code (`main.py`)

from fastapi import FastAPI from pydantic import BaseModel import mlflow.pyfunc app = FastAPI(title="MLOps Serving API") model = mlflow.pyfunc.load_model("models:/Price_Forecast_LSTM/Production") class PriceRequest(BaseModel): symbol: str recent_ohlcv: list @app.post("/api/v1/predict/price") def predict_price(payload: PriceRequest): preds = model.predict(payload.recent_ohlcv) return {"predicted_price_15m": float(preds[0][0]), "trend": "BULLISH"}
