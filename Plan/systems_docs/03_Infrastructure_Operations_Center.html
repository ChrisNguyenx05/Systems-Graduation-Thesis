1. Kafka Consumer Lag Monitoring

SYS-03 theo dõi chỉ số kafka_consumergroup_lag nhằm đảm bảo luồng xử lý Spark Streaming không bị trễ so với luồng Binance WebSocket. Nếu Lag > 5,000 msgs trong 2 phút, Prometheus Alertmanager sẽ phát cảnh báo khẩn cấp tới Telegram.

2. Metrics Pipeline Architecture

sequenceDiagram participant EXP as cAdvisor / Kafka Exporter participant PROM as Prometheus Server (9090) participant GRAF as Grafana UI (3000) participant TG as Telegram Bot Dispatcher loop Every 15 Seconds PROM->>EXP: GET /metrics EXP-->>PROM: Return OpenMetrics Text end PROM->>PROM: Evaluate Alerting Rules alt In Firing State PROM->>TG: Push Alert Payload to Telegram else Normal State GRAF->>PROM: PromQL Query PROM-->>GRAF: Time-Series Graphs end

3. Prometheus Alert Rules Configuration (`alert_rules.yml`)

groups: - name: infra_alert_rules rules: - alert: HighKafkaConsumerLag expr: sum(kafka_consumergroup_lag) > 5000 for: 2m labels: { severity: critical } annotations: summary: "Kafka Consumer Lag exceeds threshold!" description: "Spark Streaming is lagging behind Binance stream by {{ $value }} messages." - alert: ContainerDown expr: time() - container_last_seen > 30 for: 1m labels: { severity: critical } annotations: summary: "Container {{ $labels.name }} is DOWN!"
